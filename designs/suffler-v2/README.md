# Suffler v2 — design mockups

Static phone mockups (390×844) for the new Suffler, styled like Quiet Moon.
Design canvas: https://claude.ai/artifact/AVgdUM2iuQCTSRJ4EgfWEY

- `Main.dc.html` — Scripts library (home)
- `Write.dc.html` — Script editor with "Moon helper" AI
- `Record.dc.html` — Camera with teleprompter text overlay, voice follow, speed
- `Edit.dc.html` — Trim, captions, filter, music, AI cut, export 9:16

Style (from Quiet Moon): night #130a1b, plum #241532, plum-2 #331f45, line #523666,
mist #8e6fb0, rose #f3a6c4, blush #ffd9e8, gold #f0c97a, ink #f8ecf3, muted #c7aabd, ember #ff8a6b.
Fonts: Old Standard TT (display), Cormorant Garamond (quotes/titles), Cormorant SC (labels), Nunito (body).

The `.dc.html` files use a design-canvas format; treat them as visual references,
not as code to ship.
